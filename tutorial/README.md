# Native PyTorch tutorials

Execute the eight `*_pytorch.ipynb` notebooks for the native package. Each includes
pinned setup, explicit PyTorch loops, metrics, figures, and checked native
checkpoints. Full scientific workloads are the default. `NIF_SMOKE=1` is a
separate shortened development mode, not a convergence or acceptance result.

All original notebooks without the `_pytorch` suffix, including `_colab.ipynb`,
and everything in `colab_support/` are **legacy TensorFlow reference artifacts**.
They remain preserved. Their bootstrap and validation tools are not used by the
native workflows. See the repository README and `docs/PYTORCH_API.md` for native
installation and migration details.
